# FreeBSD-CLI-Calculator
una calculadora de terminal para FreeBSD.

No es una calculadora con una interfaz cli, es para sistemas que se nieguen a usar interfaces graficas o para calculos rapidos sin salir de la terminal.

CODIGO ABIERTO BAJO LA MISMA LICENCIA DE LINUX, NO LA DE BSD. USABLE EN LINUX ES MUY SIMPLE, POR AHORA.
